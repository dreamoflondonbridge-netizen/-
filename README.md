# 👑 다원중 전설의 발표왕 키우기!

중학교 국어 '발표' 단원 학습지 빈칸 복습용 픽셀 아트 육성 시뮬레이션 게임입니다.
`index.html` 파일 하나로 되어 있어서, 브라우저로 열기만 하면 바로 실행됩니다.

## 태블릿에서 바로 열기 (GitHub Pages)

아래 3단계면 학생들에게 링크 하나로 나눠 줄 수 있습니다.

1. 이 저장소의 **Settings** 탭 → 왼쪽 메뉴에서 **Pages** 클릭
2. **Source** 를 `Deploy from a branch` 로 두고,
   **Branch** 를 `claude/presentation-king-game-b5ziim` / `/ (root)` 로 선택 후 **Save**
3. 1~2분 기다리면 아래 주소가 열립니다

   **https://dreamoflondonbridge-netizen.github.io/-/**

> 저장소가 **Private** 이면 Pages 가 유료 플랜에서만 동작합니다.
> 무료 계정이라면 Settings 맨 아래에서 저장소를 **Public** 으로 바꿔 주세요.
> (게임 파일만 들어 있어 공개해도 문제되는 내용은 없습니다.)

주소가 길면 QR 코드로 만들어 칠판에 띄우거나, 클래스룸·패들렛에 링크로 올려 주세요.

## 수업에서 쓸 때

- 소리는 `▶ 발표 육성 시작!` 을 눌러야 켜집니다.
  **아이패드는 측면 무음 스위치가 켜져 있으면 소리가 나지 않습니다.**
- 진행 상황은 **그 기기 안에** 자동 저장됩니다. 앱을 전환하거나 실수로 창을 닫아도
  다시 열면 `▶ 이어서 하기` 가 나타납니다.
  기기를 바꾸거나 브라우저 기록을 지우면 저장 내용도 사라집니다.
- 한 태블릿을 여러 학생이 돌려 쓸 때는 `🔄 처음부터 새로 시작` 을 누르면
  이전 기록이 지워지고 새로 시작합니다.
- 인터넷이 없어도 작동합니다. (픽셀 폰트만 온라인일 때 적용되고, 오프라인이면 기본 글꼴로 대체)

## 문제·엔딩 수정하기

`index.html` 을 메모장이나 VS Code 로 열면 아래 부분을 고칠 수 있습니다.
주석으로 사용법을 적어 두었습니다.

| 고치고 싶은 것 | 찾을 위치 |
|---|---|
| 문제와 정답 | `const SENTENCES = [` |
| 엔딩 캐릭터 이름·설명·이미지 | `const ENDINGS = [` (`imagePath` 값 교체) |
| 점수 배점, 피버 기준 | `GAIN_BASE`, `FEVER1_COMBO`, `FEVER2_COMBO`, `PENALTY` |

### 엔딩 이미지 넣기

`ENDINGS` 배열의 `imagePath` 에 그림 경로를 적으면 됩니다.
이미지 파일이 없으면 자동으로 이모지가 대신 표시되므로 그대로 두어도 괜찮습니다.

```js
{ name:'다원중 코난', emoji:'🕵️',
  imagePath:'images/conan.png',   // ← 이 경로를 바꾸세요
```

- 같은 폴더에 두면 `"conan.png"`
- `images` 폴더에 두면 `"images/conan.png"`
- 인터넷 주소도 가능 `"https://.../conan.png"`
