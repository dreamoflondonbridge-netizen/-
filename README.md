# 👑 다원중 전설의 발표왕 키우기!

중학교 국어 '발표' 단원 학습지 빈칸 복습용 픽셀 아트 육성 시뮬레이션 게임입니다.
`index.html` 파일 하나로 되어 있어서, 브라우저로 열기만 하면 바로 실행됩니다.

## 태블릿에서 바로 열기 (GitHub Pages)

아래 3단계면 학생들에게 링크 하나로 나눠 줄 수 있습니다.

1. 이 저장소의 **Settings** 탭 → 왼쪽 메뉴에서 **Pages** 클릭
2. **Source** 를 `Deploy from a branch` 로 두고,
   **Branch** 를 `claude/presentation-king-game-b5ziim` / `/ (root)` 로 선택 후 **Save**
3. 1~2분 기다리면 아래 주소가 열립니다

   **https://dreamoflondonbridge-netizen.github.io/-/**

> 저장소가 **Private** 이면 Pages 가 유료 플랜에서만 동작합니다.
> 무료 계정이라면 Settings 맨 아래에서 저장소를 **Public** 으로 바꿔 주세요.
> (게임 파일만 들어 있어 공개해도 문제되는 내용은 없습니다.)

주소가 길면 QR 코드로 만들어 칠판에 띄우거나, 클래스룸·패들렛에 링크로 올려 주세요.

## 수업에서 쓸 때

- 소리는 `▶ 발표 육성 시작!` 을 눌러야 켜집니다.
  **아이패드는 측면 무음 스위치가 켜져 있으면 소리가 나지 않습니다.**
- 진행 상황은 **그 기기 안에** 자동 저장됩니다. 앱을 전환하거나 실수로 창을 닫아도
  다시 열면 `▶ 이어서 하기` 가 나타납니다.
  기기를 바꾸거나 브라우저 기록을 지우면 저장 내용도 사라집니다.
- 한 태블릿을 여러 학생이 돌려 쓸 때는 `🔄 처음부터 새로 시작` 을 누르면
  이전 기록이 지워지고 새로 시작합니다.
- 인터넷이 없어도 작동합니다. (픽셀 폰트만 온라인일 때 적용되고, 오프라인이면 기본 글꼴로 대체)

문제를 풀어 나가면 배경이 자동으로 바뀝니다.

| 스테이지 | 장소 | 내용 |
|---|---|---|
| 1 | 🏫 교실 | 발표 준비 과정 간단 정리 |
| 2 | 🎨 미술실 | 설명 방법 |
| 3 | 🎵 음악실 | 지수의 발표 과정 따라가기 |
| 4 | ⚽ 운동장 | 발표 준비 과정 핵심 정리 |
| 5 | 🍚 급식실 | 발표 내용 체계적으로 조직하기 |
| 6 | 🎪 강당 | 지수의 발표 내용과 매체 자료 |

마지막 문제를 풀면 **커튼이 닫혔다 열리며 강당 무대**가 시작됩니다.
총점에 따라 발표 장면이 4단계로 달라지고, 커튼이 다시 닫히면 엔딩 캐릭터가 나옵니다.

## 스탯과 엔딩 판정 기준

한 스탯은 **최대 750점**까지만 오릅니다. (750점이 되면 `MAX` 가 뜨고 더는 못 고릅니다)
한 판에서 얻을 수 있는 **총점은 최대 1130점** 입니다.

판정은 **위에서부터 순서대로** 검사해서 먼저 맞는 것으로 정해집니다.

### 1단계 — 한 스탯을 750점 만점으로 채운 경우

| 엔딩 | 조건 |
|---|---|
| 🧠 말싸움의 달인 | 논리력 750점 (만점) |
| 🎙️ 스피치의 달인 | 전달력 750점 (만점) |
| 💻 PPT의 달인 | 매체 활용도 750점 (만점) |
| ❤️ 다원중 인기쟁이 | 청중 호응도 750점 (만점) |

> 이 4개를 총점 엔딩보다 **위에** 둔 이유 : 한 스탯이 750점이면 총점도 자동으로 690점을 넘습니다.
> 아래에 두면 총점 엔딩에 먼저 걸려서 이 엔딩들이 영원히 안 나옵니다.

### 2단계 — 총점(4개 스탯의 합)으로 판정

| 엔딩 | 조건 |
|---|---|
| 👑 전설의 발표왕 | 총점 850점 이상 |
| ⚡ 발표의 신 | 총점 770점 이상 |
| 🏆 발표의 달인 | 총점 690점 이상 |
| 📘 발표의 정석 | 총점 610점 이상 |
| 📝 준비된 발표생 | 총점 530점 이상 |
| 🌱 발표 꿈나무 | 총점 430점 이상 |
| 🏃 교무실로. | 그 외 (총점 430점 미만) |

## 🔒 히든 엔딩 (5종)

조건이 특이한 엔딩입니다. 히든 엔딩이 나오면 커튼이 열렸을 때
**박수 대신 청중이 웅성거리는 장면**이 나오고, 결과 화면과 신문도 다르게 표시됩니다
(보라빛 테두리 · 신문에 '특종' 도장).

| 엔딩 | 조건 |
|---|---|
| 🤖 AI 발표 로봇 | 퀴즈 전체를 **5분(300초) 안에** 끝냄 |
| ⚖️ 완벽주의자 | 4개 스탯이 **완전히 똑같은 점수** |
| 🎧 ASMR 유튜버 | **전달력 0점** |
| 📄 텍스트 테러리스트 | **매체 활용도 0점** |
| 🎪 아무말 대잔치 | **논리력 0점** |

판정 순서는 `AI 로봇 → 완벽주의자 → 달인 4종 → 0점 히든 3종 → 총점 6단계 → 교무실로` 입니다.
한 스탯을 만점(750점)까지 채운 학생은 다른 스탯이 0이어도 **달인 엔딩**이 먼저 나옵니다.

> **0점이 여러 개일 때** : 예를 들어 논리력만 올린 학생은 전달·매체·호응이 모두 0입니다.
> 이럴 때 항상 ASMR만 나오면 재미없으므로, **0점인 스탯 중 하나를 무작위로 골라** 판정합니다.
> (호응도가 뽑히면 해당 히든 엔딩이 없으므로 총점 엔딩으로 넘어갑니다)
> 항상 같은 순서로 정해지길 원하시면 `ENDINGS` 의 `zeroPick === 'deliv'` 를
> `s.deliv === 0` 처럼 바꾸면 됩니다.

### 히든 엔딩이 몇 명이나 나올까

한 스탯에 몰아주는 학생은 나머지가 0으로 남기 때문에 생각보다 자주 나옵니다.
33명 학급 시뮬레이션 결과:

| 몰아주기 하는 학생 비율 | 히든 엔딩 인원 |
|---|---|
| 20% | 3명 |
| 40% | 6명 |
| 55% | 8~9명 |
| 70% | 11명 |

**더 드물게 만들려면** `ENDINGS` 에서 0점 히든 3종의 조건을 아래처럼 바꾸세요.
0인 스탯이 **딱 하나뿐일 때만** 발동하게 되어 거의 나오지 않습니다.

```js
cond:(s, total, sec, zeroPick) =>
     s.deliv === 0 && STAT_KEYS.filter(k => s[k] === 0).length === 1
```

## 엔딩 연출 순서

마지막 문제를 풀면 아래 순서로 진행됩니다.

1. **암전** — 화면이 까매지고 주인공의 혼잣말이 두 번 나옵니다
   - "후.. 드디어 모든 준비가 끝났다."
   - "떨리지만, 연습했던 걸 전부 보여주는 거야!"
2. **커튼 열림** — 강당 무대에 엔딩 캐릭터가 등장하고
   "수많은 청중의 시선이 당신에게 집중됩니다" 문구가 뜹니다
3. **커튼 닫힘**
4. **신문 기사** — 『다원일보』가 화면에 펼쳐지며 엔딩 캐릭터의 후일담을 보도합니다
   (`→ 결과 확인하기` 버튼을 눌러야 넘어가므로 천천히 읽을 수 있습니다)
5. **엔딩 카드** — 최종 스탯과 엔딩 캐릭터

### 대사·기사 고치기

- 암전 혼잣말 : `index.html` 의 `const DARK_LINES = [` 부분
- 신문 기사 : `ENDINGS` 배열 안 각 엔딩의 `news:{ headline:'제목', body:'내용' }`
- 연출 길이 : `const FINALE_MS = {` 부분 (숫자 단위는 1/1000초. 2900 = 2.9초)
- 신문 제호(『다원일보』)나 기자명 : `index.html` 에서 `다 원 일 보` 로 검색

`{이름}` 이라고 적으면 학생이 정한 발표자 이름으로 자동 치환됩니다.

## 난이도 조절하는 법

33명 학급 기준으로 시뮬레이션해서 정한 값입니다.
예상 분포 : 달인 7명 / 전설의 발표왕 1~2명 / 나머지는 달인~준비된 발표생 구간.

**더 쉽게** 하려면 위 6개 숫자를 **전부 똑같이 빼면** 됩니다.
**더 어렵게** 하려면 전부 똑같이 더하면 됩니다.

| 조정 | 결과 |
|---|---|
| 전부 -80점 | 한 단계씩 쉬워짐 (전설의 발표왕 3~4명) |
| 그대로 | 전설의 발표왕 1~2명 |
| 전부 +80점 | 한 단계씩 어려워짐 (전설의 발표왕 거의 안 나옴) |

- 총점 기준은 `index.html` 의 `ENDINGS` 배열에서 `cond:(s, total) => total >= 850` 부분을 고칩니다.
- 달인 엔딩 기준은 `const STAT_MAX = 750;` 한 줄만 바꾸면 게이지까지 같이 바뀝니다.
  - **달인이 너무 많이 나오면** 이 숫자를 올리세요 (800 → 더 적어짐)
  - **너무 적게 나오면** 내리세요 (700 → 더 많아짐)

> **달인 엔딩은 "한 능력만 몰아서 올린 학생"만 받을 수 있습니다.**
> 그래서 인원수는 점수 기준보다 **몇 명이 그 전략을 쓰느냐**에 더 크게 좌우됩니다.
> 시작 화면에 힌트를 넣어 두었지만, 수업 전에 한 번 더 말해 주면 도전하는 학생이 늘어납니다.
> 반대로 아무 말 안 하면 달인 엔딩은 2~4명 정도로 줄어듭니다.

## 올리는 방법 (GitHub 홈페이지에서, 프로그램 설치 없이)

1. 그림을 컴퓨터에 내려받고, 위 표대로 **파일 이름을 바꿉니다.**
   (윈도우: 파일 우클릭 → 이름 바꾸기)
2. 이 저장소 첫 화면에서 **`images` 폴더를 클릭**해 들어갑니다.
3. 오른쪽 위 **`Add file` → `Upload files`** 를 누릅니다.
4. 이름을 바꿔 둔 그림 파일들을 **화면 안으로 끌어다 놓습니다.** (여러 개 한 번에 됩니다)
5. 화면 아래 초록색 **`Commit changes`** 버튼을 누릅니다.
6. 1~2분 뒤 게임 주소를 새로 고치면 그림이 나옵니다.

> **주의** : 반드시 `images` **폴더 안으로 들어간 뒤에** 업로드하세요.
> 저장소 첫 화면에서 바로 올리면 폴더 밖에 저장돼서 그림이 안 나옵니다.
> (잘못 올렸으면 그 파일을 클릭 → 휴지통 아이콘으로 지우고 다시 올리면 됩니다)

## 잘 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 이모지만 나오고 그림이 안 나옴 | 파일 이름 오타, `images` 폴더 밖에 올림, 확장자가 `.jpg` 인데 이름은 `.png` |
| 그림이 너무 크게/작게 나옴 | 크기는 자동으로 맞춰집니다. 비율(가로세로)을 위 표대로 맞춰 보세요 |
| 무대 그림에 흰 네모가 보임 | 투명 배경이 아닌 그림입니다. 배경을 지운 PNG 로 다시 저장하세요 |
| 바꿨는데 그대로임 | 태블릿에서 새로 고침(당겨서 새로 고침)을 하거나, 1~2분 뒤 다시 열어 보세요 |

> `.jpg` 그림을 쓰고 싶으면, `index.html` 의 `ENDINGS` 에서 해당 줄의
