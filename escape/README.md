# 🏫 폐교 방탈출 — 논증의 방

중학교 2학년 국어 '논증의 짜임(연역 · 귀납)' 복습용 웹 방탈출 게임입니다.
`escape/index.html` 파일 하나로 되어 있어 브라우저로 열기만 하면 바로 실행됩니다.
(외부 음원·이미지 없이 소리는 Web Audio API 로 합성하고, 방은 CSS 로 그립니다.
 인터넷이 없어도 글꼴만 기본 글꼴로 바뀔 뿐 그대로 동작합니다.)

## 학생들에게 링크로 나눠 주기 (GitHub Pages)

1. 저장소 **Settings → Pages**
2. **Source** 는 `Deploy from a branch`,
   **Branch** 를 `claude/cool-franklin-ikj7gy` / `/ (root)` 로 선택 후 **Save**
3. 1~2분 뒤 아래 주소가 열립니다

   **https://dreamoflondonbridge-netizen.github.io/-/escape/**

> 저장소가 Private 이면 Pages 는 유료 플랜에서만 동작합니다. 무료 계정이면 Public 으로 바꿔 주세요.
> (발표왕 게임을 Pages 로 쓰는 중이라면 브랜치를 하나만 고를 수 있으니, 두 게임을 같은 브랜치에 두거나
>  한 번에 하나씩 골라 주세요.)

## 게임 구조

| Stage | 방 | 분위기 | 미니게임 |
|---|---|---|---|
| 1 | 버려진 교실 | 바람 · 풍경 소리 | 지우개로 칠판 문지르기, UV 랜턴 비추기 |
| 2 | 잠긴 교무실 | 시계 초침 · 저음 | 달력 찢기, 교과서 페이지(44) 입력, 복사기 스캔 |
| 3 | 문 닫힌 과학실 | 가스 · 기계음 | 토치 가열 게이지, 현미경 초점, 자석으로 쇳가루 쓸기, 셀로판지 안경 |
| 4 | 학교 창고 | 라디오 잡음 · 심장 소리 | 주파수 44.4 맞추기, 장기 드래그, 동전으로 얼룩 긁기 |

각 방에서 쪽지 6장(연역 3 + 귀납 3)을 모아 문 자물쇠에서
**두 세트로 나누고 · 순서를 세우고 · 유형(연역/귀납)을 판별**해야 문이 열립니다.
귀납 세트는 전제 ①②의 순서가 바뀌어도 정답으로 처리합니다.
Stage 4를 풀면 암전 → 천장 페이드인 → "아... 꿈이다!!!" → 총 소요 시간 결과 창이 나옵니다.

## 수업에서 쓸 때

- 소리는 `들어간다` 를 눌러야 켜집니다. **아이패드는 측면 무음 스위치를 확인**해 주세요.
  상단바 `♪` 버튼으로 언제든 끌 수 있습니다.
- 상단바 `◎` 버튼은 방 안의 상호작용 가능한 물건 위치를 1.8초 동안 점선으로 비춥니다.
- 진행 상황은 그 기기 안에 자동 저장됩니다. 다시 열면 `이어서 하기` 가 나타나고,
  `↺` 버튼으로 처음부터 시작할 수 있습니다.
- 드래그가 어려운 기기에서는 **카드를 누른 뒤 놓을 자리를 누르는** 방식도 그대로 동작합니다.

## 문장 고치기

`index.html` 의 `const NOTES = {` 부분에서 24개 문장을 수정할 수 있습니다.
`k` 는 논증 유형(`ded` 연역 / `ind` 귀납), `r` 은 역할
(`p1` 대전제 · `p2` 소전제 · `p` 귀납 전제 · `c` 결론)입니다.
