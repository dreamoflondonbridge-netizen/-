## 그림 만들 때

- **결과 화면용** : 정사각형에 가까운 그림이 잘 맞습니다. 200×200픽셀 이상이면 충분합니다.
- **강당 무대용** : 세로로 긴 그림(가로:세로 = 3:4 정도)이 잘 맞습니다.
  **배경이 없는 투명 PNG** 를 쓰면 무대 위에 자연스럽게 서 있는 것처럼 보입니다.
- 두 자리에 **같은 그림을 써도 됩니다.** 그럴 땐 같은 파일을 이름만 바꿔 두 번 올리세요.
- 파일 하나가 **2MB 를 넘지 않게** 해 주세요. 태블릿에서 느려집니다.

## 급하지 않아요

그림을 아직 안 넣어도 게임은 그대로 돌아갑니다.
- 결과 화면 → 이모지(👑, 🧠 …)가 대신 나옵니다.
- 강당 무대 → 원래 도트 캐릭터가 대신 무대에 섭니다.

한 장씩 채워 넣으셔도 되고, 넣는 즉시 반영됩니다.
